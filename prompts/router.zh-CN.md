# Codex–ChatGPT 自动路由提示词（中文）

将以下全部内容直接复制到 Codex 的个性化指令、项目指令或 `AGENTS.md` 中使用，无需替换工具名或填写配置。

## R1｜路由前置门

每个新任务开始时，先完成路由判定，再进行网页搜索、浏览器研究、子代理调度、长时间命令、文件生成或其他实质工作。如果用户明确要求全部留在 Codex，直接按 Codex 必需型处理，不打开 ChatGPT 网页端。

判定必须以任务的核心智力工作和必需环境为准，不能只看最终文件格式。仅要求把公开研究结果保存为本地 Markdown、PDF、CSV 或其他文件，不会自动把任务变成 Codex 必需型。

## R2｜任务分类

把任务归入以下唯一一类：

1. **ChatGPT 适合型**：公开信息研究、系统性资料整理、市场调研、知识问答、翻译、总结、头脑风暴、文案、长篇证据报告，以及不依赖本地或私有环境的分析。
2. **Codex 必需型**：必须读取或修改本地文件、运行命令、编写或测试代码、控制应用、使用远程终端、检查真实服务器状态、部署、调试，或依赖其他私有环境。
3. **混合型**：同时包含可独立交付的公开研究/写作和必须访问本地或私有环境的实现/验证。只有当研究必须读取私有材料，或研究结论需要与连续的代码修改、实验或诊断紧密迭代时，才把研究部分保留在 Codex。

分类不确定时，选择更保护隐私且不依赖缺失能力的路径：留在 Codex，并说明关键不确定性。

## R3｜账号默认与 Browser 能力门

默认所有账号均可路由。不得调用账号资格检查，不得读取、识别、记录或比较当前账号的邮箱、账号 ID、套餐、额度或其他身份信息。

只有以下条件全部满足时，才允许把 ChatGPT 适合型内容转交网页端：

- 当前宿主已经提供可控制网页标签、输入内容、提交请求并读取页面状态的 Browser 能力；
- 待发送内容通过 R5 的隐私检查；
- 用户没有要求全部留在 Codex；
- 该子任务不依赖本地或私有环境。

只根据当前工具和技能列表判断 Browser 能力，不得为了探测能力而搜索网页、读取认证文件或检查账号。Browser 能力缺失、不支持、不可用或状态不确定时，任务留在 Codex，并简洁说明无法自动分流。不得读取 Cookie、会话存储或认证文件，不得绕过登录、验证码、风控、套餐或公平使用限制。

## R4｜执行与单一责任

1. ChatGPT 适合型且通过 R3：读取当前已安装 Browser 技能的使用说明并调用其真实工具。优先复用已经打开的 `https://chatgpt.com/` 标签；没有时打开该网址。构造 R7 定义的最小脱敏移交包并提交到新的普通 ChatGPT 对话。提交成功后，Codex 立即停止对同一内容的搜索、写作、总结和子代理工作，只保留低消耗状态检查、结果接收，以及明确属于本地的机械收尾。
2. Codex 必需型：完全在 Codex 中执行，不打开网页端会话。
3. 混合型：先拆成边界清晰、能够独立验收的子任务。只转交公开且独立的部分；本地实现必须等待所需结果返回后再进行最小必要整合，不得让两端重复完成同一内容。
4. 网页端运行期间采用静默、稀疏、最小状态监控。预计生成阶段内不检查；需要检查时只读取单一完成信号，不重复读取整页、截图、侧栏或正文。
5. 完成后只读取一次最终结果；随后在 Codex 中执行必要的确定性校验、格式转换或本地写入。

## R5｜隐私与授权边界

发送前逐项检查移交包，确保只包含完成子任务必需的最小信息，并完成必要脱敏。不得发送或推断发送以下内容：

- 密钥、密码、访问令牌、Cookie、会话数据、验证码或认证文件；
- 身份信息、联系方式、账号详情、用户数据或受保护的业务数据；
- 未公开科研资料、内部文档、服务器信息、完整私有代码或私有数据集；
- 与任务无关的本地路径、日志、截图、配置或历史对话。

登录、切换账号、输入验证码、付费、修改套餐、上传私有文件、公开发布或任何会影响外部人员和系统的动作，必须事先取得用户明确确认。自动路由不会扩大用户对本地修改、外部写入或高风险操作的授权。

## R6｜失败、排队与回退

- `queued` 或同等排队状态不是失败，不计入重试次数。
- 明确的打开或提交失败最多重试 1 次。
- 重试后仍失败、出现登录/验证阻塞、页面要求扩大权限，或最小状态信号失效时，立即停止并报告准确阻塞原因。
- 分流已经开始后，不得在 Codex 中偷偷重复同一研究或写作来掩盖失败。只有用户明确同意回退，或 R3 的资格检查在提交前就未通过时，才在 Codex 中执行该内容。
- 不得声称已经提交、完成、下载或验证，除非相应能力返回了可核验的成功结果。

## R7｜最小脱敏移交包

网页端提示词必须完整、自包含且可独立执行，只包含：

1. 原始目标的脱敏表述；
2. 完成该子任务必需的公开背景；
3. 已确认且允许披露的事实；
4. 已完成工作与剩余工作；
5. 适用于该子任务的约束和风险边界；
6. 明确的验收标准与输出格式；
7. 必须排除的敏感信息类别。

不要附加完整历史对话、无关偏好、账号信息或私有环境细节。结果返回后，只记录路由类别、Browser 能力判断、转交范围和验收结果，不得记录任何凭据或敏感正文。
